# DFL edge-confidence を用いた辺単位 loss 制御：現状整理と研究仮説

## 1. 研究目的

CrowdHuman の半教師あり物体検出（SSOD）において、DFL（Distribution Focal Loss）の edge-level confidence を用いて、

> **pseudo box 全体を捨てるのではなく、局所的に不確かな辺の DFL supervision だけを抑制する**

方法の効果と、その作用機序を明らかにする。

本研究で重要なのは、DFL confidence を単なる pseudo-label quality score として扱うのではなく、

\[
\boxed{\text{boundary difficulty / ambiguity の検出信号}}
\]

として利用する点である。

---

# 2. 現在の実装が実際に行っていること

当初は、

```text
DFL confidence が低い
→ pseudo box を reliable から uncertain / ignore に降格
```

と想定していた。

しかし実装確認の結果、これは誤りだった。

実際には、

> **reliable pseudo box はそのまま保持し、低 DFL-confidence edge の DFL loss だけを mask する**

という処理である。

pseudo-label transition は以下。

| Labeled ratio | reliable → reliable | reliable → uncertain | reliable → ignore |
|---|---:|---:|---:|
| 10% | 183,986 | 0 | 0 |
| 1% | 193,196 | 0 | 0 |

したがって、DFL edge-confidence 法は、

- pseudo box selection を変更しない
- classification target を変更しない
- box / IoU supervision を変更しない
- low-confidence edge の **DFL supervision のみ**を抑制する

手法である。

より正確には、

\[
\boxed{\text{edge-wise DFL supervision masking}}
\]

である。

---

# 3. Baseline と DFL edge-confidence の性能

CrowdHuman の best mAP50:95：

| Method | 10% labeled | 1% labeled |
|---|---:|---:|
| Supervised matched | 0.42803 | 0.33558 |
| weight=0.10 | 0.45792 | 0.38108 |
| weight=0.25 | 0.46077 | 0.38033 |
| EMA denominator | 0.45277 | 0.32672 |
| Fixed denominator | 0.44821 | 0.34641 |
| loss_balance | **0.46686** | 0.37668 |
| DFL edge-confidence | **0.46349 ± 0.00602** | **0.38175 ± 0.00662** |

### 10% labeled

\[
0.46686\;(\text{loss\_balance}) > 0.46349\;(\text{DFL})
\]

DFL edge masking による改善は確認できない。

### 1% labeled

\[
0.37668 \rightarrow 0.38175
\]

で、

\[
+0.00507
\]

の平均改善が確認された。

したがって現時点では、

> **DFL edge masking の効果は、特に極端な low-label regime で現れる可能性がある**

という結果である。

---

# 4. Random count-matched masking との比較

DFL-selected masking の効果が、

> 「適切な edge を選択した効果」

なのか、

> 「単に一部の DFL loss を減らした regularization」

なのかを分離するため、count-matched random masking を行った。

Random variant は、各 batch で DFL-selected が mask する edge 数

\[
k_L,k_T,k_R,k_B
\]

と完全に同じ数だけ、位置をランダムに選んで mask する。

## 1% labeled の結果

| Method | Seeds | best mAP50:95 | best mAP50 |
|---|---:|---:|---:|
| No mask / loss_balance | 1 | 0.37668 | 0.67590 |
| Random count-matched mask | 3 | 0.37810 ± 0.00589 | 0.67909 ± 0.00405 |
| DFL-selected mask | 3 | **0.38175 ± 0.00662** | **0.68590 ± 0.00426** |

平均として、

\[
\boxed{\text{DFL-selected} > \text{Random} > \text{No mask}}
\]

となった。

DFL-selected − Random の best mAP50:95 差：

- seed 0: +0.01040
- seed 1: -0.00281
- seed 2: +0.00335
- mean: **+0.00365**

### 解釈

現時点では、

> **DFL supervision を減らすこと自体に regularization 効果がある可能性に加えて、DFL confidence で mask 位置を選ぶことにも小さな追加効果がある**

と解釈できる。

ただし、

- seed 1 では Random が上回る
- No-mask は seed 0 のみ

ため、selection 効果はまだ強い統計的結論ではない。

---

# 5. DFL が選ぶ edge は実際に難しいか

GT box を画像範囲へ正しく clip した後、baseline teacher の pseudo edge を GT と比較した。

## 1% validation

| Visibility | Mask status | n | Mean pseudo-to-GT edge error | Mean DFL confidence |
|---|---|---:|---:|---:|
| visible | DFL-masked | 131 | **77.07 px** | 0.515 |
| visible | non-masked | 160,271 | 9.36 px | 0.988 |
| occluded | DFL-masked | 295 | **52.64 px** | 0.507 |
| occluded | non-masked | 44,111 | 19.57 px | 0.968 |

occluded bottom edge でも、

- DFL-masked: **49.14 px**
- non-masked: **33.69 px**

となった。

以前見られた

> 「bottom では DFL-masked の方が誤差が小さい」

という例外は、GT full-body box を画像範囲へ clip していなかったことによる artifact だった。

clip 後は、

\[
\boxed{\text{DFL-masked edge は non-masked edge より実際に GT error が大きい}}
\]

という関係が一貫している。

したがって、

> **low DFL confidence edge は、実際に難しい / 誤差の大きい pseudo-boundary を濃縮している**

という主張は、clip 修正後の方が強くなった。

---

# 6. 遮蔽と DFL confidence の関係

GT clipping 後も、edge occlusion と DFL confidence の負の関係は維持された。

Pearson correlation：

| Labeled ratio | Left | Top | Right | Bottom |
|---|---:|---:|---:|---:|
| 1% | -0.093 | -0.067 | -0.095 | **-0.302** |
| 10% | -0.136 | -0.089 | -0.144 | **-0.364** |

bottom edge で最も強い。

したがって、

\[
\boxed{\text{bottom occlusion}\uparrow \Rightarrow \text{DFL confidence}\downarrow}
\]

という傾向は artifact ではない。

ただし DFL confidence は occlusion detector そのものではない。

visible edge でも low-confidence かつ large-error な edge が存在するため、より正確には、

\[
\boxed{\text{boundary difficulty / ambiguity detector}}
\]

として解釈する。

---

# 7. Final prediction における効果

GT clipping 後、confidence-only baseline と DFL model の最終 prediction を同一 GT に one-to-one matching して edge error を比較した。

\[
\Delta e = e_{\rm DFL} - e_{\rm baseline}
\]

で、負ほど DFL model が良い。

## 1% labeled: strongly-occluded bottom edge

| DFL seed | n | Mean delta | Median delta | Improved rate |
|---|---:|---:|---:|---:|
| 0 | 12,013 | -2.04 px | -0.31 px | 51.7% |
| 1 | 12,568 | -2.00 px | -0.53 px | 52.2% |
| 2 | 12,456 | -1.47 px | -0.15 px | 50.9% |
| 3-seed mean ± SD | — | **-1.84 ± 0.32 px** | — | — |

GT clip 前の結果は

\[
-1.73 \pm 0.26\text{ px}
\]

であり、clip 後も効果の方向と規模は維持された。

### Absolute error

| Model | Matched strong-bottom edges | Mean edge error | Median edge error |
|---|---:|---:|---:|
| confidence-only | 14,659 | 34.49 px | 18.21 px |
| DFL seed 0 | 15,204 | 33.17 px | 17.96 px |
| DFL seed 1 | 16,439 | 33.92 px | 17.85 px |
| DFL seed 2 | 16,442 | 33.05 px | 17.52 px |

したがって 1% 条件では、

> **strongly-occluded bottom boundary の localization error が、DFL masking により3 seedすべてで改善している**

ことが確認された。

## 10% labeled

strong-bottom paired delta：

- seed 0: +0.03 px
- seed 1: +0.20 px
- seed 2: +0.52 px

したがって 10% では、

> **DFL edge masking による strongly-occluded bottom localization 改善は支持されない**

という結果である。

# 8. 現時点で支持される作用機序

ここまでの結果をつなぐと、現在最も自然な説明は以下。

```text
Occlusion / boundary difficulty
        ↓
DFL confidence が低下
        ↓
その edge は実際に pseudo-to-GT error が大きい
        ↓
DFL-selected masking により、その edge の DFL supervision を抑制
        ↓
pseudo box / classification / box loss は維持
        ↓
極端な low-label 条件では、strongly-occluded boundary の最終 localization error が改善
```

重要なのは、

> **box全体を捨てるのではなく、意味情報を残したまま、局所的に危険な DFL supervision だけを弱めている**

点である。

---

# 9. 1% と 10% の違い

## 1%

- DFL-selected masking が mAP で小幅改善
- strongly-occluded bottom edge の最終 localization が改善
- 3 seed すべて同方向

## 10%

- mAP では loss_balance baseline を超えない
- strongly-occluded bottom edge も改善しない

この違いは、

\[
\boxed{\text{labeled boundary coverage が少ないほど、誤った pseudo-boundary supervision の影響が大きい}}
\]

という仮説と整合する。

ただし、この原因自体はまだ直接検証していない。

---

# 10. 現在の中心仮説

## H1: 危険性

> GT から大きくずれた pseudo-edge に対する DFL supervision は self-training に有害である。

未検証。次の Oracle dose-response で直接確認する。

## H2: labeled coverage dependency

> 曖昧な boundary supervision の害は、labeled data における同種の boundary coverage が低いほど大きい。

1% vs 10% の違いはこの仮説と整合するが、まだ直接検証していない。

## H3: error amplification

> wrong pseudo-edge の誤差は self-training の反復で増幅し、boundary drift / box expansion / cross-object contamination を生む。

未検証。

## H4: detection

> DFL の分布形状は難しい / 曖昧な edge を検出できる。

現在かなり支持されている。

根拠：

- DFL-masked edge の pseudo-to-GT error が大きい
- occlusion、とくに bottom occlusion と DFL confidence が負に相関
- GT clipping 修正後も関係が維持
- bottom の旧例外は artifact と判明

## H5: intervention

> 難しい edge の DFL supervision を抑制すると、最終 localization と SSOD 性能が改善する。

予備的に支持。

根拠：

- 1%で DFL-selected > Random > No-mask の平均傾向
- strongly-occluded bottom edge が 3 seeds で改善

ただし効果量は小さく、No-mask のseed不足もある。

# 11. 次の実験：Oracle wrong-edge dose-response

DFL confidence を使わず、GTをOracleとして

> 本当に間違っている edge

を特定し、その DFL supervision の重みを操作する。

## Oracle wrong-edge

pseudo edge と GT edge の normalized error：

\[
e_L=\frac{|\hat l-l^{GT}|}{w_{GT}},\qquad
e_R=\frac{|\hat r-r^{GT}|}{w_{GT}}
\]

\[
e_T=\frac{|\hat t-t^{GT}|}{h_{GT}},\qquad
e_B=\frac{|\hat b-b^{GT}|}{h_{GT}}
\]

について、

\[
e_e\ge0.10
\]

を wrong edge と定義する。

GT box は必ず画像範囲へ clip 後に使用する。

## Weight

\[
w\in\{0,1,5,20\}
\]

- `w=0`: wrong-edge DFL supervision を抑制
- `w=1`: baseline
- `w=5`: moderate amplification
- `w=20`: strong amplification

2 seeds。

Primary prediction：

\[
w=0 > w=1 > w=5 > w=20
\]

少なくとも、

\[
w=20 < w=1
\]

なら、

> wrong pseudo-edge に対する DFL supervision 自体が有害

というH1を直接支持する。

---

# 12. Oracle実験で特に注意する実装

## GT clipping

CrowdHuman の `fbox` / `vbox` は画像外へ伸びるため、GTは必ず

\[
[0,W]\times[0,H]
\]

へ clip してから、matching、edge error、wrong-edge 判定に使用する。

今回修正した共通 `gt_features()` と同じ処理を再利用する。

## Student coordinate system

teacher frame 上で wrong edge を決め、その mask をそのまま student loss に渡さない。

augmentation 後の student coordinate system で pseudo box と GT box を同じ座標系に揃えた上で edge error を計算する。

horizontal flip 時の L/R 入れ替えに注意。

## Edge-wise DFL loss

Oracle weight は4辺をreduceする前の

\[
\ell_L,\ell_T,\ell_R,\ell_B
\]

へ適用する。

## Assigner mapping

pseudo object の wrong-edge mask は、TaskAlignedAssigner が返す object identity を使って、その object に assign された全 positive prediction へ伝播する。

後処理でIoU再matchingしない。

## Total DFL scale

`w=5,20` で総 DFL loss が単純に増える confound を避けるため、eligible edge 全体で平均 weight が1になるよう正規化する。

したがって、

> wrong edge へ相対的に supervision を集中させた効果

を測る。

## w=1 equivalence

Oracle code path の `w=1` が original loss_balance baseline と数値誤差範囲で一致することをfull training前に必ず確認する。

# 13. 現時点での最も妥当な研究ストーリー

現在の結果は、

\[
\boxed{\text{DFL confidenceを使ったpseudo-label filtering}}
\]

よりも、

\[
\boxed{\text{boundary-level pseudo-supervision control}}
\]

として整理する方が自然である。

想定する機序は、

\[
\boxed{
\text{Boundary ambiguity}
\rightarrow
\text{large pseudo-edge error}
\rightarrow
\text{harmful DFL supervision}
\rightarrow
\text{self-training error propagation}
}
\]

である。

DFL confidence は、

\[
\boxed{\text{危険な boundary supervision を GTなしで検出する proxy}}
\]

として位置付ける。

もし Oracle dose-response で H1 が成立すれば、

1. wrong-edge supervision は実際に有害
2. DFL confidence はそのようなedgeを検出できる
3. DFL masking はその害を部分的に抑制する

という一貫したストーリーになる。

---

# 14. 現時点の結論

> **DFL edge-confidence は、SSOD における難しい pseudo-boundary を検出する信号として機能している。低-confidence edge は実際に大きな pseudo-to-GT localization error を持ち、特に CrowdHuman の bottom occlusion と強く関係する。これらのedgeに対する DFL supervisionを選択的に抑制すると、1% labeled 条件では strongly-occluded bottom boundary の最終 localization が3 seedで一貫して改善し、count-matched random maskingより平均性能も高い。一方10%条件では同様の改善は見られない。したがって、edge-level pseudo-supervision の有害性とその self-training 中の増幅機構を、Oracle dose-response および時間発展解析で直接検証する必要がある。**
